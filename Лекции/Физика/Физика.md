# КОНСПЕКТ: МЕХАНИКА И КИНЕМАТИКА

## 1. Механика

**Механика** — раздел физики, изучающий механическое движение тел и причины его изменения.

**Механическое движение** — изменение положения тела или его частей относительно других тел с течением времени.

Механика делится на:

- **Кинематику** — изучает движение тел без рассмотрения причин движения.
    
- **Динамику** — изучает движение и причины, вызывающие его изменение.
    
- **Статику** — изучает условия равновесия тел.
    

### Основные физические модели

**Материальная точка** — тело, размерами которого в данной задаче можно пренебречь.

**Абсолютно твёрдое тело** — тело, расстояние между любыми двумя точками которого считается неизменным.

Можно ли считать тело материальной точкой, зависит **не от его реальных размеров, а от условий задачи**.

### Система отсчёта

Движение всегда рассматривается относительно чего-либо.

**Система отсчёта = тело отсчёта + система координат + часы.**

---

# 2. Положение материальной точки

В декартовой системе координат положение точки определяется координатами:

**x, y, z**

или радиус-вектором:

**r⃗ = x i⃗ + y j⃗ + z k⃗**

где **i⃗, j⃗, k⃗** — единичные векторы вдоль осей x, y, z.

При движении координаты зависят от времени:

**x = x(t)**  
**y = y(t)**  
**z = z(t)**

или в векторной форме:

**r⃗ = r⃗(t)**

Это **кинематические уравнения движения материальной точки**.

---

## 3. Степени свободы

**Число степеней свободы** — количество независимых координат, необходимых для определения положения тела.

Примеры:

- движение в пространстве → **3** степени: x, y, z;
    
- движение по плоскости → **2**;
    
- движение вдоль линии → **1**;
    
- математический маятник → **1** (угол φ).
    

---

# 4. Траектория, путь и перемещение

**Траектория** — линия, по которой движется точка.

**Путь S** — длина участка траектории.

**Перемещение Δr⃗** — вектор из начального положения точки в конечное:

**Δr⃗ = r⃗₂ − r⃗₁**

В координатах:

**Δr⃗ = Δx i⃗ + Δy j⃗ + Δz k⃗**

Модуль перемещения:

**|Δr⃗| = √(Δx² + Δy² + Δz²)**

Важно:

**S ≥ |Δr⃗|**

Путь равен модулю перемещения только при **прямолинейном движении без изменения направления**.

Это важное уточнение к формулировке из лекции.

---

# 5. Скорость

## Средняя скорость

Средняя **векторная** скорость:

**v⃗ср = Δr⃗ / Δt**

Она показывает, какое перемещение совершено за единицу времени.

## Мгновенная скорость

**v⃗ = dr⃗/dt**

Вектор скорости направлен **по касательной к траектории в сторону движения**.

Модуль скорости:

**v = |v⃗|**

В координатах:

**v = √(vₓ² + vᵧ² + v𝓏²)**

Связь скорости с путём:

**v = dS/dt**

Отсюда:

**dS = vdt**

и путь за промежуток времени:

**S = ∫vdt**

То есть на графике **v(t)** путь соответствует площади под графиком скорости.

---

# 6. Ускорение

**Ускорение** показывает, как изменяется вектор скорости:

**a⃗ = dv⃗/dt**

Скорость может изменяться:

1. по **величине**;
    
2. по **направлению**.
    

Поэтому ускорение раскладывают на две составляющие:

**a⃗ = a⃗τ + a⃗ₙ**

## Тангенциальное ускорение

**a⃗τ = (dv/dt)τ⃗**

Отвечает за **изменение величины скорости**.

- aτ > 0 → скорость увеличивается;
    
- aτ < 0 → скорость уменьшается;
    
- aτ = 0 → модуль скорости постоянен.
    

## Нормальное ускорение

**a⃗ₙ = (v²/R)n⃗**

где **R** — радиус кривизны траектории.

Нормальное ускорение отвечает за **изменение направления скорости** и направлено к центру кривизны.

Модуль:

**aₙ = v²/R**

Общее ускорение:

**a = √(aτ² + aₙ²)**

Итого запомнить:

**aτ → меняет величину скорости**  
**aₙ → меняет направление скорости**

Этого для конспекта достаточно — длинный вывод формулы нормального ускорения можно не переписывать.

---

# 7. Обратная задача кинематики

Если известно ускорение **a⃗(t)** и начальные условия, можно найти скорость и положение тела.

Так как:

**a⃗ = dv⃗/dt**

то:

**v⃗(t) = v⃗₀ + ∫₀ᵗ a⃗(t)dt**

А поскольку:

**v⃗ = dr⃗/dt**

то:

**r⃗(t) = r⃗₀ + ∫₀ᵗ v⃗(t)dt**

То есть:

**ускорение → интегрируем → скорость → интегрируем → положение.**

---

# 8. Кинематика твёрдого тела

Основные виды движения:

### Поступательное движение

Все точки тела движутся одинаково: их перемещения параллельны и равны.

Для всех точек тела одинаковы:

**v⃗ и a⃗**

### Вращение вокруг неподвижной оси

Все точки тела движутся по окружностям, центры которых находятся на **оси вращения**.

У всех точек тела одинаковы:

- угол поворота **φ**;
    
- угловая скорость **ω**;
    
- угловое ускорение **ε**.
    

Но линейная скорость зависит от расстояния до оси.

---

# 9. Угол поворота

При вращении положение тела удобно описывать не перемещением отдельной точки, а **углом поворота φ**.

Элементарный угол:

**dφ**

Направление вектора углового перемещения определяется **правилом правого винта (буравчика)**.

---

# 10. Угловая скорость

**Угловая скорость** — скорость изменения угла поворота:

**ω = dφ/dt**

Направление **ω⃗** совпадает с осью вращения и определяется правилом правого винта.

Связь линейной и угловой скорости:

**v = ωR**

где **R** — расстояние точки от оси вращения.

Также:

**dS = R dφ**

---

# 11. Угловое ускорение

**Угловое ускорение** — скорость изменения угловой скорости:

**ε = dω/dt**

Связь с линейным ускорением:

**aτ = εR**

**aₙ = v²/R = ω²R**

Очень важная группа формул:

**v = ωR**

**aτ = εR**

**aₙ = ω²R = v²/R**

---

# 12. Векторные формулы вращения

Для точки, находящейся на расстоянии **ρ⃗** от оси:

**v⃗ = ω⃗ × ρ⃗**

Тангенциальное ускорение:

**a⃗τ = ε⃗ × ρ⃗**

Полное ускорение:

**a⃗ = ε⃗ × ρ⃗ + ω⃗ × v⃗**

То же самое можно представить как:

**a⃗ = a⃗τ + a⃗ₙ**

Эти формулы особенно пригодятся дальше при решении задач.

---

# 13. Равномерное вращение

Если:

**ε = 0**

то угловая скорость постоянна:

**ω = const**

Угол:

**φ = φ₀ + ωt**

---

# 14. Равнопеременное вращение

Если:

**ε = const**

то:

**ω = ω₀ + εt**

**φ = φ₀ + ω₀t + εt²/2**

Знак **+ или − отдельно писать необязательно**: направление уже учитывается знаком величин **ω** и **ε**. Это аккуратнее, чем запись «±» из презентации.

---
